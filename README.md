# رويال فالي للسياحة

موقع عربي باتجاه RTL مبني بـ Next.js App Router، TypeScript وTailwind CSS 4، مع تصدير ثابت جاهز للاستضافة.

## التشغيل

```sh
npm install
npm run dev
```

افتح `http://localhost:3000`.

```sh
npm run typecheck
npm run build
```

ملفات النسخة الإنتاجية موجودة في `out/`. لأن المشروع يستخدم `output: "export"`، ارفع محتويات هذا المجلد إلى استضافة ملفات ثابتة. أمر `next start` لا يُستخدم مع التصدير الثابت.

## التعديل

- `src/lib/site.ts`: أرقام الاتصال والبريد وواتساب وروابط السوشيال والدومين.
- `src/app/page.tsx`: المحتوى والأقسام؛ الصفحة Server Component لتحسين تحميل المحتوى وSEO.
- `src/components/`: القائمة المتجاوبة، الهوية البصرية، ظهور العناصر، وأيقونات السوشيال.
- `src/app/globals.css`: ثيم Tailwind والألوان وتنسيقات المكونات والتجاوب.
- `public/images/`: الصورة التي تم توفيرها والشعار الأصلي. الهوية في القائمة مرسومة كـ SVG والنص قابل للقراءة في مختلف المقاسات.
- `public/fonts/`: خط Cairo محفوظ محليًا، يُحمّل باستخدام `next/font/local`.

## بيانات تُستكمل لاحقًا

- أضف روابط فيسبوك وإنستجرام وتيك توك الرسمية في `site.social`. الأيقونات الحالية توضح أن الرابط سيُضاف قريبًا ولا تفتح حسابات غير موثوقة.
- استبدل الرمزين المؤقتين في قسم الفريق بصور المسؤولين وأسمائهم بعد توفيرها.
- حدّث `site.url` عند ربط الدومين النهائي، ثم أعد البناء لتحديث canonical وOpen Graph وsitemap وJSON-LD.
- يمكن إضافة تفاصيل وأسعار برامج الحج والعمرة بعد اعتمادها. الأزرار الحالية تفتح استفسار واتساب حسب الخدمة، وليست نظام حجز أو دفع.

## الجودة

عناوين دلالية وبيانات SEO وOpen Graph وJSON-LD وsitemap وrobots، نصوص بديلة للصور، تحميل مسبق لصورة الهيرو، خطوط محلية، دعم لوحة المفاتيح وقائمة موبايل، واحترام `prefers-reduced-motion`. التنسيقات تعتمد على Tailwind مع CSS مخصص للتكوين البصري والأنيميشن.
